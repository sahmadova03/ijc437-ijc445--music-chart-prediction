# Instructions for Running the Code

This document provides step-by-step instructions for running the R scripts included in this repository.  
The analysis follows a fully reproducible data science pipeline, from data acquisition to model evaluation and visualisation.

---

## System Requirements
- R (version 4.0 or higher recommended)
- RStudio (recommended for ease of use)
- Internet connection (required for dataset download via Kaggle API)

---

## Dataset Access (Kaggle API)
The dataset is downloaded programmatically using the Kaggle Command Line Interface (CLI).

To enable dataset download, users must:
1. Create a Kaggle account.
2. Generate a Kaggle API token (`kaggle.json`) from Kaggle account settings.
3. Place the `kaggle.json` file in the appropriate local directory as required by Kaggle.
4. Ensure that the Kaggle CLI is installed and accessible from the system path.

For security reasons, the `kaggle.json` file is **not included** in this repository.

> **Alternative:**  
> The dataset can also be downloaded manually from Kaggle and placed in the `billboard_data/` directory if the Kaggle CLI is not available.

---

## Running the Analysis

The scripts must be executed in the order listed below.  
Each script depends on objects created in previous steps.

1. `00_setup.R`  
   Installs and loads all required R packages.

2. `01_data_loading.R`  
   Downloads the dataset via the Kaggle API and loads it into R.

3. `02_data_cleaning.R`  
   Cleans the dataset and constructs the binary target variable (Top 50 vs Not Top 50).

4. `03_train_test_split.R`  
   Creates stratified training and test datasets.

5. `04_text_cleaning.R`  
   Cleans and prepares textual data (song titles and lyrics).

6. `05_tfidf_feature_engineering.R`  
   Generates TF-IDF features from lyrics using training data only.

7. `06_metadata_features.R`  
   Creates and standardises metadata features and combines them with TF-IDF features.

8. `07_model_training_and_evaluation.R`  
   Trains multiple machine learning models and evaluates predictive performance.

9. `08_visualisation_IJC437.R`  
   Produces model evaluation visualisations for IJC437.

10. `09_visualisation_IJC445.R`  
    Produces interpretability and uncertainty-focused visualisations for IJC445.

---

## Outputs
Selected visual outputs generated by the analysis are available in the `outputs/figures/` directory.  
These figures support model evaluation, interpretability, and uncertainty analysis.

---

## Notes
- Scripts are designed to be run sequentially.
- No code logic has been modified from the original working script; the pipeline has been modularised for clarity and reproducibility.
